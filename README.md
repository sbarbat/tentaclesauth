# Tentacles Auth - OAuth MCP for your AI Agents

Tentacles is an OAuth MCP Server that you can use to connect a number of OAuth providers to your MCP AI agents using a single MCP server.

At the moment you can connect:
- Facebook
- Instagram
- X (Twitter)
- Reddit
- Xero
- Monzo
- Github
..and much more coming. Ask for the connector you need as Issues.
