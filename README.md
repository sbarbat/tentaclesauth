# Tentacles Auth - OAuth MCP for your AI Agents

Tentacles is an OAuth MCP Server that you can use to connect a number of OAuth providers to your MCP AI agents using a single MCP server.

A connector is a service that you can use you own account to get your own data from. For example you might connect your Github account to list all your repositories, get a list of the open PRs, answer them, etc.

At the moment you can connect:
- Facebook
- Instagram
- X (Twitter)
- Reddit
- Xero
- Monzo
- Github

..and much more coming. Ask for the connector you need as Issues.

Works with any AI that supports MCP.
